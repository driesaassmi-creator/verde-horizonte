Git Cheat Sheet

De commando's die je nodig hebt om je website te updaten.

1. Bekijk wat je hebt aangepast

Laat zien welke bestanden je hebt gewijzigd of toegevoegd.

git status

2. Voeg wijzigingen toe aan de wachtrij

Zeg tegen Git: "Deze bestanden moeten mee in de volgende save game."

git add .

3. Maak een Save Game (Commit)

Sla de wijzigingen op met een duidelijk labeltje tussen de haakjes.

git commit -m "Mijn update"

4. Stuur naar de Cloud (Push)

Stuur alles naar GitHub. Vercel update je website dan automatisch.

git push
