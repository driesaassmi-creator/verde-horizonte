Case Study: De Boeken-bib

Hoe ik leerde bouwen, testen en durfde te vereenvoudigen.

De Uitdaging

Ik wilde een online bibliotheek bouwen met drie lagen (eigen werk, kinderboeken, fictie) achter een beveiligde login. Ik wist nog niet veel, dus ik leunde zwaar op AI.

Mijn Oplossing

Ik bouwde een volledig werkend systeem met HTML, CSS, JavaScript en een inlogsysteem. Ik leerde werken met databases, Git en het oplossen van bugs.

Het Resultaat

De bib werkt en staat online. Maar ik leerde ook een belangrijke les: een ingewikkelde login is niet altijd nodig. Daarom heb ik de boeken nu openbaar gemaakt op deze site, zonder drempels.
